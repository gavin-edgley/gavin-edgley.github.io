Privacy Policy

Last updated: 31 October 2026

Lab Assistant ("the app") is a private tool used only by its operator, with the operator's own Google account. This policy explains how the app handles Google user data.

Data the app accesses

  • Gmail messages (read-only): to help the operator review and organise their own inbox.
  • Gmail drafts: to prepare draft messages for the operator to review. The app does not send email on its own.
  • Calendar events: to view the operator's schedule and add events they request.

How data is used, stored and shared

  • Data is used only to provide these features to the operator.
  • Data and access tokens are stored on private, non-public hardware protected by access controls.
  • Google user data is never sold, never used for advertising, and never shared with third parties, except where required by law.
  • Google user data is not used to develop, improve or train generalised AI or machine-learning models.

Limited Use

The app's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Retention and deletion

Data is kept only as long as it is useful to the operator. Access can be revoked at any time at myaccount.google.com/permissions, after which stored tokens stop working and are deleted.
